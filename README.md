# ForLabs

Приложение делает лабораторную работу по методичке и выдаёт отчёт `.docx`, свёрстанный как итоговые отчёты колледжа: титул, содержание, шапка, задания, листинги в рамке, рисунки, контрольные вопросы, вывод. Пишет текст модель DeepSeek; оформление, нумерацию, подписи и вывод делает программа, поэтому они всегда одинаковые.

## Что умеет сейчас (этап 1)

- Профили студентов: ФИО, пол («Изучил» / «Изучила», «Выполнил» / «Выполнила»), группа, варианты (по журналу и по номеру рабочего места), руководители и учебный год по предметам. Профилей может быть сколько угодно.
- Разбор методички (PDF, DOCX, текст, фото через Tesseract): тема, цель, оснащение, задания дословно со сквозной нумерацией (дополнительные — продолжением), варианты из приложений, контрольные вопросы. Перед выполнением всё показывается на проверку.
- Текст отчёта по каждому заданию, ответы на вопросы (коротко, для тетради), вывод строго по цели.
- Проверки: стандарт РС02-23 и анти-ИИ (запрещённые слова, ИИ-штампы, одинаковые начала абзацев, стиль кода, дизайн без ИИ-шаблонов, сходство с работами других профилей). Найденное модель переписывает точечно.
- Схемы рисуются автоматически (строгий чёрно-белый стиль). Скриншоты программ — слоты «вставь через Ctrl+V» с подсказкой, что заснять.
- Вёрстка по канону, снятому с эталонных отчётов (`docs/reference/formatting-canon.md`), и автоматическая сверка с ним.
- Доводка через Word: номера страниц в содержании и «Продолжение листинга N» по реальной разбивке Word. Без Word — LibreOffice.
- Отчёт за семестр: титул + содержание + выбранные лабы.
- Несколько пользователей через Supabase: вход по e-mail, данные каждого видны только ему, ключ модели хранится в облаке и пользователям не виден.

Дальше по плану: этап 2 — сам код (C#, Java, Go, PHP, HTML/CSS) с запуском и настоящими скриншотами окон; этап 3 — 1С; этап 4 — сети.

## Установка на Windows

1. Поставь Python 3.11+ с https://www.python.org/downloads/ (отметь «Add python.exe to PATH»).
2. Скачай репозиторий (Code → Download ZIP) и распакуй, например, в `D:\ForLabs`.
3. Запусти `Установка.bat`. В конце он покажет, что найдено: Word, LibreOffice, браузер для схем.
4. Запускай `Запуск.bat` — откроется окно ForLabs.

## Первый запуск (облачный режим)

**Владельцу, один раз:**

1. Запусти ForLabs и **зарегистрируйся первым**: первый аккаунт становится администратором и одобрен сразу.
2. Ключи модели: либо выдай каждому свой ключ в разделе **Админ** (см. ниже), либо задай общий — в Supabase **Edge Functions → Secrets → Add new secret**, имя `LLM_API_KEY`. Общий ключ работает у тех, кому он разрешён и у кого нет своего.

**Друзьям:** установить так же, нажать «Регистрация», подтвердить почту по ссылке из письма Supabase. Затем администратор открывает **Админ**, заходит в карточку нового участника и нажимает «Одобрить аккаунт».

## Админ-панель

Раздел **Админ** виден только администратору в облачном режиме.

- **Обзор:** участники, подписки, ключи, остаток на ключах у провайдера, расход токенов за 30 дней (график по участникам), новые лабы по неделям. Под графиками — «Числа» с таблицей.
- **Карточка участника** (клик по строке):
  - подписка: «+7 дней», «+30 дней», «До этой даты», «Без срока», «Забрать сейчас», отключить аккаунт. Продление считается от текущей даты окончания, если она ещё не прошла. После окончания подписки модель для участника не работает, свои лабы он по-прежнему видит и скачивает;
  - ключ: вставить, заменить, убрать; разрешить или запретить общий ключ. Ключ хранится в Supabase Vault зашифрованным, участник его не видит, в панели — только последние 4 символа и остаток у провайдера;
  - профили (ФИО, группа, предметы), расход по дням, лабы с токенами на каждую и скачиванием отчёта .docx, история действий, имя и заметка («оплатил за ноябрь»).
- Участник видит у себя в шапке срок подписки, а в **Настройках** — остаток на своём ключе.

Работать без облака можно: **Настройки → Локально** и свой ключ API.

## Как сделать лабу

1. **Профили → Новый профиль**: ФИО, пол, группа, отметь предметы и варианты.
2. **Лабы → Новая лаба**: выбери предмет, перетащи методичку.
3. Проверь вкладку «Разбор методички» (задания дословно, вопросы, вариант) и нажми **Выполнить**.
4. В «Нужно от тебя» выбери рисунок и вставь скриншот (Ctrl+V).
5. Проверь страницы и замечания, нажми **Сдать в папку сдачи** — файл появится в папке сдачи профиля.

## Чат правок

У каждой лабы слева есть панель **Правки**. Напиши, что сказал преподаватель («в задании 3 добавь вывод таблицы», «перепиши вывод короче»), можно приложить фото замечаний — модель поправит только нужные места и пересоберёт документ. На вопрос («почему тут цикл for?») она просто ответит. Галочка «Запомнить для следующих лаб» сохраняет требование преподавателя по этому предмету — список виден на странице лабы, лишнее можно удалить. Каждая правка — новая версия, к любой из последних 10 можно вернуться.

Пожелания и отклонения от методички (и фото к ним) можно написать сразу при создании лабы — они учитываются при разборе и выполнении.

## Если что-то пошло не так

- **Пропал интернет.** Запросы к облаку повторяются; если связи нет, видны свои профили и лабы из копии на компьютере (сверху жёлтая плашка). Работа с моделью продолжится, когда связь вернётся.
- **Выключился ноутбук посреди работы.** Готовые части отчёта сохраняются по ходу. На странице лабы будет кнопка **Продолжить** (дописать недостающее) или **Пересобрать документ** (если текст готов). Файлы пишутся так, что обрыв не оставляет испорченный файл вместо прежнего.
- **Отчёт открыт в Word.** ForLabs попросит закрыть файл и пересобрать — ничего не теряется.
- **«Защищённое соединение не прошло проверку».** Сеть колледжа или антивирус проверяют HTTPS. ForLabs доверяет сертификатам Windows; если не помогло — другая сеть или ForLabs в исключения антивируса.
- **Второй запуск** не открывает вторую копию: окно уже запущенного ForLabs выходит вперёд.
- **Журнал ошибок** — `%LOCALAPPDATA%\ForLabs\forlabs.log`. Его стоит приложить, если пишешь о проблеме.

## Правила

Раздел **Правила** — тексты, которые получает модель (стандарт, голос студента, анти-ИИ, правила по предметам). Их можно править, правки хранятся у тебя. Вёрстка, нумерация, подписи и вывод правилами не меняются: их делает программа.

## Для разработки

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
pytest                      # быстрые тесты
FORLABS_API_KEY=… pytest -m live   # живые тесты с моделью
python -m forlabs --browser        # интерфейс в браузере
```

- `forlabs/` — код: `core` (модели, хранилище, LLM, правила), `ingest`, `spec`, `report`, `antiai`, `render`, `pipeline`, `cloud`, `ui`.
- `rules/` — правила для модели.
- `supabase/` — миграции базы и функция-прокси `llm`.
- `tools/extract_exemplars.py` — снятие канона с эталонных отчётов; `tools/live_run.py` — живой прогон; `tools/ui_screens.py` — скриншоты интерфейса.
- Спецификация и план: `docs/superpowers/`.
