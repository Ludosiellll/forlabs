# ПСИП — Проектирование веб-систем (веб-разработка, HTML и CSS)

## Дисциплина
Создание веб-страниц на HTML и CSS. Редактор — Sublime Text, результат смотрят в браузере.
- структура HTML-документа (html, head, title, body), атрибуты body (bgcolor, text), заголовки h1–h6, p, pre;
- физическое форматирование (b, i, u, s, sub, sup, font) и логическое (strong, em, blockquote, q, cite, mark);
- подключение таблицы стилей style.css, виды селекторов, состояния ссылок, списки, формы, таблицы;
- табличная сетка страницы и позиционирование (position: relative, absolute, fixed; top, bottom, left, right);
- адаптивная вёрстка: viewport, относительные единицы (%, rem, em), media queries.

## Тема сайта
- Со второй лабы все работы — продолжение одной темы сайта студента. Тема, страницы, тексты, палитра и уже сделанные файлы приходят в блоке «Память предмета».
- Продолжай её: те же названия, разделы, тексты и цвета; новое добавляй к уже сделанному.
- Если памяти нет, не изображай «продолжение»: делай по заданию и назови тему сайта явно в первом абзаце.

## Код
- только теги и свойства из этой и прошлых лаб;
- устаревшие теги и атрибуты (font, bgcolor) используй, если их требует задание;
- без фреймворков и JavaScript, если задание их не требует;
- файлы: index.html, другие страницы по заданию, style.css;
- оформление — по правилам дизайна: палитра и образ от темы сайта, без ИИ-штампов.

## Что писать в задании
- 1–2 предложения: какой файл создан и какие теги или свойства применены, с именами: «В файле index.html заголовки оформлены тегами h1–h3, цитата — тегом blockquote».
- Если задание требует расчёт (процентные ширины, rem), приведи формулу и числа.
- Для селекторов и медиазапросов — короткий список: селектор или условие и что он меняет.

## Рисунки
- страница в браузере по каждому заданию: «Страница index.html с оформлением заголовков и абзацев», «Ссылки в четырёх состояниях», «Форма бронирования со стилями»;
- адаптивная вёрстка — по рисунку на ширину: компьютер (1280×800), планшет (768×1024), телефон (375×812);
- если рисунок снимает студент, инструкция: какой файл открыть в браузере, какую ширину окна выставить, на что навести или нажать, что должно быть видно.

## Листинги
- HTML и CSS — отдельными листингами: «HTML-код страницы index.html», «Код таблицы стилей style.css».
