# Проверка на Windows (то, что нельзя проверить в облачном контейнере)

Приложение разрабатывалось в Linux-контейнере без Word. Всё ниже нужно один раз пройти на ПК с Windows и Word.

1. `Установка.bat` → в конце «Microsoft Word: есть», «Браузер для схем: есть».
2. `Запуск.bat` → открывается окно ForLabs (не браузер). Если открылся браузер — не установился pywebview, это не мешает работе.
3. Новая лаба по любой методичке с кодом длиннее страницы → «Выполнить» → после вставки скриншотов в журнале есть «Доводка документа», в правой колонке нет жёлтого предупреждения про Word.
4. Скачать .docx, открыть в Word:
   - листинг, переходящий на следующую страницу, разорван, сверху новой страницы — «Продолжение листинга N»;
   - Файл → Сведения: автор — из профиля;
   - Word не предлагает «восстановить содержимое».
5. Отчёт за семестр из 2+ лаб → в содержании верные номера страниц (Ctrl+клик по строке ведёт к лабе).
6. Таблица длиннее страницы (если есть) → «Продолжение таблицы N» и повтор строки заголовка.
7. Схема в теоретической лабе рисуется (Edge установлен в Windows по умолчанию).

Если в пунктах 3–6 что-то не так — пришли журнал лабы (вкладка «Журнал») и сам .docx.
