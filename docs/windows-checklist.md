# Проверка на Windows (то, что нельзя проверить в облачном контейнере)

Приложение разрабатывалось в Linux-контейнере без Word. Всё ниже нужно один раз пройти на ПК с Windows и Word.

1. `Установка.bat` → в конце «Microsoft Word: есть», «Браузер для схем: есть».
2. `Запуск.bat` → открывается окно ForLabs (не браузер). Если открылся браузер — не установился pywebview, это не мешает работе.
3. Новая лаба по любой методичке с кодом длиннее страницы → «Выполнить» → после вставки скриншотов в журнале есть «Доводка документа», в правой колонке нет жёлтого предупреждения про Word.
4. Скачать .docx, открыть в Word:
   - листинг, переходящий на следующую страницу, разорван, сверху новой страницы — «Продолжение листинга N»;
   - Файл → Сведения: автор — из профиля;
   - Word не предлагает «восстановить содержимое».
5. Отчёт за семестр из 2+ лаб → в содержании верные номера страниц (Ctrl+клик по строке ведёт к лабе).
6. Таблица длиннее страницы (если есть) → «Продолжение таблицы N» и повтор строки заголовка.
7. Схема в теоретической лабе рисуется (Edge установлен в Windows по умолчанию).

8. Сбои (проверялись в Linux-контейнере на заглушках, на Windows — вживую):
   - `Запуск.bat` (pythonw, без консоли) открывает окно; в `%LOCALAPPDATA%\ForLabs\forlabs.log` есть строки запуска;
   - второй `Запуск.bat` не открывает вторую копию, окно первой выходит вперёд;
   - закрыть окно во время «Выполнить» → вопрос «Идёт работа над лабой…»; после повторного запуска — «Продолжить» и отчёт дописывается;
   - выключить Wi-Fi → главная и лабы открываются из копии, сверху плашка «Нет связи»; включить — плашка пропадает;
   - открыть report.docx в Word и нажать «Пересобрать документ» → просьба закрыть файл, не «Internal Server Error»;
   - доводка через Word: окна активации Office или «Безопасный режим» не вешают ForLabs навсегда (через 5 минут WINWORD закрывается, отчёт остаётся без доводки);
   - окно ForLabs (WebView2) открывается на чистой Windows 10 и 11;
   - LibreOffice и Tesseract (если стоят) находятся в «Настройках» и работают на русских путях `C:\Users\Иван\…`;
   - Kaspersky/ESET/Avast с проверкой HTTPS: вход в облако и модель работают (или понятное сообщение о сертификате);
   - вход запоминается между запусками (Диспетчер учётных данных Windows → «ForLabs»).

Если в пунктах 3–8 что-то не так — пришли журнал лабы (вкладка «Журнал»), `forlabs.log` и сам .docx.
