# Канон оформления (снят с 4 итоговых отчётов: ССП, 1С, ПССИП, КС)

Источник: forlabsnotes/Итоговые_отчеты/*.docx (commit 1da8dce). Значения — эффективные (с учётом docDefaults → стиль → прямое форматирование). Где ручное оформление расходится, взято самое частое значение (доля указана).

## Страница
- A4 210×297, поля: верх 20, низ 20, лево 30, право 15 мм (pgMar 1134/1134/1701/850), колонтитулы 12,5 мм.
- Колонтитулы пустые, номеров страниц нет. Одна секция.

## Документ (итоговый за семестр)
1. Титульный лист (копируется из шаблона, подставляются: предмет, ФИО «Д.Я. Лабынцев», группа, руководитель, учебный год).
2. «Содержание» — настоящее поле TOC `\o "1-3" \h \z \u` по Heading 1, заголовок стилем TOC Heading (по центру, жирный 14, before 12).
3. Каждая лаба — с новой страницы (пустой абзац с разрывом страницы), заголовок «Лабораторная работа №N» стилем Heading 1.

## Рамка листинга
Каждая строка кода (и пустые строки внутри листинга) несёт одинаковую границу абзаца — Word склеивает их в одну рамку:
`<w:pBdr>` top/bottom: single, sz=4 (0,5 pt), space=1, color=auto; left/right: single, sz=4, space=4, color=auto.
Подпись «Листинг N – …» — над рамкой, без рамки. Выравнивание строк кода — по ширине (как в оригинале: длинные переносимые строки растягиваются).
При переходе на новую страницу рамка разрывается: в конце страницы рамка закрывается, на новой странице — абзац «Продолжение листинга N» (вне рамки), затем рамка продолжается. Место разрыва определяется по реальной вёрстке Word (LibreOffice ошибается на 1–2 строки — проверено на ССП ЛР3).

## Рисунки
- Только «в тексте» (inline), абзац по центру, без рамки у картинки.
- Ширина: по ширине текста 16,5 см (медиана во всех отчётах), если исходная картинка шире; мелкие окна — в натуральную величину. Высота ограничена так, чтобы рисунок с подписью помещался на страницу.

## Различия по предметам (метки шапки)
- ССП, 1С: «Тема работы:», «Цель работы:», [«Оснащение:»], «Задание:».
- ПССИП, КС: «Тема:», «Цель:», «Задание:», «Оснащение работы:».
