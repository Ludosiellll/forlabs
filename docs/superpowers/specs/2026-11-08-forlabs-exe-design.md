# ForLabs: exe, установщик, обучение, защита — дизайн

Владелец выбрал вид установщика: вариант 2.6 (родной стиль Windows 11, движение из исходников Microsoft Fluent/WinUI;
холст https://claude.ai/artifact/789uGAq3ge4DGMizae2SXd). Подпись кода — пока без сертификата. 1С — после этого этапа.

## Что получает студент
1. Один файл `ForLabsSetup.exe` (страница Releases на GitHub).
2. Установщик в стиле 2.6: «Начало» → «Папка и ярлыки» → «Установка» (настоящий прогресс по файлам) → «Готово».
   Ставит в `%LOCALAPPDATA%\Programs\ForLabs` без прав администратора, ярлыки в «Пуске» (и на рабочем столе по выбору),
   строка в «Параметры → Приложения» (удаление). Повторный запуск — «Обновить», закрыв работающий ForLabs.
3. Первый запуск ForLabs — обучение (тот же стиль): подсветка настоящих кнопок, короткие карточки шагов; можно пропустить
   и пройти заново из «Настроек».
4. Удаление: «Параметры → Приложения → ForLabs → Удалить» — убирает программу и ярлыки; данные (лабы, вход)
   по вопросу «удалить и данные?».

## Устройство
- **ForLabs.exe** — Nuitka standalone (папка `ForLabs.dist`): Python скомпилирован в машинный код, `.py` и `.pyc` нет.
  Точка входа `run_forlabs.py`: `multiprocessing.freeze_support()` (дочерний процесс Word), флаги `--selfcheck`,
  `--uninstall`, `--browser`.
- **Правила и подсказки модели** — внутри exe: при сборке `tools/embed_rules.py` превращает `forlabs/rules/**/*.md`
  в модуль-константу (с простым шифрованием, чтобы не находились поиском строк); `RuleBook` берёт встроенные, если они есть.
  Папки `rules` рядом с exe нет. Свои правки студента — как раньше, в папке данных.
- **ForLabsSetup.exe** — Nuitka onefile: интерфейс 2.6 в окне WebView2 (pywebview) + `payload.zip` (сжатая
  `ForLabs.dist`). Установка: распаковка с прогрессом (байты), ярлыки (.lnk через WScript.Shell), реестр
  `HKCU\…\Uninstall\ForLabs`, запуск ForLabs. Нет WebView2 — сообщение и установка WebView2 (загрузчик Microsoft
  в составе установщика), затем снова наш интерфейс.
  Режим без окна `--silent --target <папка>` — для проверки в CI.
- **Сборка** — GitHub Actions `windows-latest`, Python 3.12, Nuitka; после сборки на настоящем Windows:
  `ForLabs.exe --selfcheck` (правила > 0, морфология, шаблоны, сервер `/health`), установка `--silent`,
  запуск установленного `--selfcheck`, удаление `--uninstall --silent`. Тег `v*` — релиз с `ForLabsSetup.exe`.

## Защита (честно)
Невзламываемых программ нет. Что делаем: машинный код вместо Python-байткода; правила/подсказки внутри exe;
ключи моделей и подписки — только на сервере (облако проверяет доступ при каждом запросе к модели), в exe нет
секретов — копия программы без аккаунта бесполезна. **Репозиторий сейчас публичный** — исходники видны всем;
сделать его приватным может только владелец (GitHub → Settings → Danger Zone).

## Ошибки и сбои
Обрыв установки — повторный запуск дописывает (распаковка во временную папку и замена); занятый файл
(ForLabs открыт) — просьба закрыть; нет места — понятный текст; антивирус удалил файл — `--selfcheck` при первом
запуске и сообщение «переустанови».

## Проверка
Юнит-тесты (Linux): ядро установщика с подменой реестра/ярлыков, встроенные правила, точка входа, обучение (HTML).
Сквозная — в CI на Windows (выше). Вручную на ноутбуке — по `docs/windows-checklist.md`.
