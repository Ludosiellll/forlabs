# Задания отдельными файлами и проект практики (черновик проекта)

Владелец: «они хотят отдельным файлом делать сами задания, скринить и вставлять в отчёт основной… нужно два варианта
работы, обычный как был и вот когда такая»; «что делать, если приложение уже сделано и по нему делаются отчёты по
всем практическим — что, как и куда». Образец — общий отчёт студентки по учебной практике (ПЗ 1–3).

## Что видно по образцу

- Задание в отчёте: «Задание N. текст», фраза «… представлен(ы) на рисунке/рисунках N–M», снимки страниц отдельного
  документа (по одной или по две страницы на снимок) либо слайдов (по четыре на снимок), подписи «Рисунок N – …».
- Ответы на контрольные вопросы — тоже снимком отдельного документа. Вывод — текстом.
- Не все задания файлами: описание предметной области и обзор аналогов в ПЗ 1 остались текстом в отчёте.
- На каждом документе — личная картинка студентки (метка, чей документ).

## Режим «Задания отдельными файлами»

**Включение.** Галочка «Задания — отдельными файлами, в отчёте их снимки»: на форме «Новая лаба», на вкладке
разбора, просьбой в чате. Значение по умолчанию — у предмета в профиле (практика — включено, остальное — нет).
Обычный режим не меняется.

**Что создаётся.** Для каждого задания — документ Word в папке сдачи: `ПЗ2/Задание 2 — Интервью.docx`; для ответов
на контрольные вопросы — `ПЗ2/Ответы на контрольные вопросы.docx`. Оформление — то же, что у отчёта. Содержимое
документа — то, что модель сейчас пишет в задание отчёта (абзацы, списки, таблицы, листинги, рисунки программы).
Заголовок документа модель даёт сама («Техническое задание на приложение …»).

**Что в отчёте.** Вместо содержимого задания — подводка и снимки страниц его документа с подписями. Снимки делает
сам ForLabs: документ → PDF → картинки страниц (тот же путь, что у предпросмотра отчёта), поля обрезаются. Окно
Word не имитируется. Задание со снимком, который должен сделать студент (чужая программа), остаётся в обычном виде,
пока снимок не вставлен: документ собирается, когда в нём всё есть.

**Презентации.** Задание «составьте презентацию» — настоящий файл PowerPoint (заголовок и текст на слайде, простая
тема), в отчёте — снимки слайдов по четыре. Нужна новая зависимость (python-pptx) в сборке. Отдельный шаг после
документов Word.

**Метка студента.** В профиле — необязательная картинка; ставится в левый верхний угол первой страницы каждого
документа задания и на первый слайд.

**Чат.** Правка задания пересобирает его документ и снимки. В «Где что лежит» перечислены файлы заданий — на вопрос
«где документы» чат отвечает путями. Правило «отдельных документов ForLabs не создаёт» действует только в обычном
режиме.

**Как устроено.** `LabSpec.task_files: bool`, `Enrollment.task_files: bool`. Содержимое задания по-прежнему хранится
блоками в `TaskSection.blocks` — это исходник документа. Вёрстка в режиме файлов: для каждого задания собрать
документ (`build_task_doc` — общий с отчётом писатель блоков), снять страницы, подставить в отчёт производную секцию
«подводка + рисунки» (`as_screens`), дальше обычная вёрстка, нумерация рисунков и сверка с эталоном. Файлы в папке
сдачи ведутся тем же списком своих файлов, что и проект программы.

## Проект практики (приложение одно на все работы)

Сейчас программа прикрепляется к каждой работе заново («Своя программа»), а тема переходит между работами через
память предмета. Нужно: прикрепить один раз.

- В профиле у предмета — «Папка проекта»: путь к папке приложения студента.
- Каждая новая работа этого предмета берёт её как «свою программу» сама (читается заново — приложение растёт);
  на форме видно «Проект предмета: Макет 3D» и можно снять.
- Что это даёт: документы (ТЗ, модели, описание) пишутся про настоящее приложение по его коду и README; листинги —
  из его файлов; снимки окон — если ForLabs может его запустить, иначе их делает студент.
- Ограничения, как у «Своей программы»: читается до 60 000 знаков кода (главные файлы первыми); приложение со
  скриптами, запускающими другие программы, ForLabs сам не запускает.

## Что уже выяснено пробой

- Документ задания из блоков отчёта → PDF → картинка страницы собирается существующим путём (LibreOffice без Word;
  с Word — тот же путь, что у отчёта). Поля обрезаются простым сравнением с белым фоном.
- В документе задания не нужны рамка страницы образца, «Продолжение таблицы» и закреплённые разрывы: документ
  задания собирается в виде «без разрывов» (он уже есть с версии 1.0.22) и без рамки.
- Сейчас для заданий-документов автор отчёта ставит рисунок «документ в MS Word», а агент по кнопке «Сделать
  снимки в программах» набирает документ в Word заново — другим текстом, чем в отчёте, медленно и ненадёжно.
  В режиме файлов этот путь не нужен: файл создаётся сразу и с тем же текстом.
- Прошлые работы, вставленные в общий отчёт снимками, уже читаются (1.0.22) — режим файлов этому не мешает:
  работа, сделанная в ForLabs, берётся из его блоков, а не со снимков.

## Порядок

1. Документы Word заданий + снимки в отчёт + галочки + чат (основное).
2. Проект практики у предмета.
3. Метка студента.
4. Презентации PowerPoint.
