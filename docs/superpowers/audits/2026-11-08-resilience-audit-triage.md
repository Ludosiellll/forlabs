# Аудит устойчивости (ветка lab-chat, 7b04fd5) — разбор находок

Аудит сделал независимый проверяющий; скрипты-воспроизведения лежали в scratchpad (s1…s16).
Исправляются отдельной веткой `resilience` после слияния чата; каждое исправление — тест, воспроизводящий сбой.

## В работу (по эффекту для студента)

| № | Что | Исправление |
|---|---|---|
| C1 | `Запуск.bat` (pythonw) — uvicorn падает: stdout/stderr = None | вывод в лог-файл, `use_colors=False`; лог приложения (I13) |
| C2 | выключение во время ответов/вёрстки → можно сдать без контрольных вопросов | `qa.missing` в стандарте; render отказывает на неполном отчёте; сохранять перед render |
| C3 | зависший/прерванный Word держит report.docx | Word работает с копией, `os.replace` при успехе; PID WINWORD — kill при тайм-ауте и при старте; вопрос при закрытии окна во время работы |
| C4 | облако: удаление лабы оставляет кэш, новая лаба читает старую методичку | delete_lab чистит кэш и файлы облака; create_lab чистит source; `_taken` по строке |
| C5 | скриншот WebP/битый навсегда ломает вёрстку | проверка/перекодирование в PNG при вставке; вёрстка не падает на битой картинке |
| C6 | обрезанные JSON (settings, subjects, profiles, state, session) роняют приложение | `atomic_write_text` с fsync и повторами; чтение без падений (`.broken`) |
| I1 | статус «Выполняется» застревает; облако без повторов | повторы в `_rest`; `_fail` не бросает; «Продолжить» при executing без задачи |
| I2 | report.docx открыт в Word | понятная ошибка; кнопка «Пересобрать», а не «Продолжить» |
| I3 | правка/скриншот теряются при выключении во время вёрстки | сохранять перед render |
| I4 | голая «Internal Server Error» | общий обработчик → error.html + лог; перевод частых ошибок ОС; `safe_name` обрезает |
| I5 | порядок переименования черновика | сохранить под новым номером → удалить черновик → `moved` |
| I6 | два экземпляра на одной папке | блокировка; второй открывает окно первого |
| I7 | облако без связи — ничего не открывается | чтение из локального кэша «только чтение» |
| I8 | ответ обрезан по длине / контекст / тайм-ауты | `finish_reason=length`, «методичка слишком большая», меньший MAX_SOURCE_CHARS |
| I9 | двойной клик «Разобрать» → две лабы | блокировка кнопки + одноразовый токен формы |
| I10 | облако гоняет мегабайты | лёгкий `list_labs`; версии без `source_text` (сделано в чате) |
| I11 | «Сдать» ждёт память; копирование не атомарно | память в фоне; копия через tmp + replace |
| I12 | HTTPS-инспекция антивируса/колледжа | `truststore` (системные сертификаты Windows) |
| I13 | нет журнала ошибок | лог в data_home с ротацией |

## Мелкие (решение по каждому — в журнале ветки resilience)
M1 часы/401 refresh · M2 сбой refresh не повторяется · M3 logout на всех устройствах · M4 LibreOffice старый PDF/очистка/зависание ·
M5 предпросмотр удаляет страницы до новых · M6 выключение во время document.save · M7 админка без сети молча на главную ·
M8 Tesseract без тайм-аута · M9 EventBus.wait на time.time · M10 ctx.reset во время задачи · M11 журнал без времени, бесконечный ·
M12 429 без Retry-After и пугающий текст · M13 httpx.Client не закрывается · M14 ошибки ОС по-английски
