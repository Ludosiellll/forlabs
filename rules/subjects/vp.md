# ВП — Веб-программирование (PHP и MySQL)

## Дисциплина
Серверная веб-разработка на PHP с базой данных MySQL на локальном сервере (localhost).
- базы данных через phpMyAdmin: создание БД и таблиц, связи FOREIGN KEY, запросы с JOIN, выгрузка дампа в .sql;
- клиент-серверные приложения на PHP: HTML-формы, передача данных методами GET и POST, обработка и проверка данных, запись в БД и в файл, капча, многошаговые формы.

## Код
- PHP — в стиле методички: тот же способ подключения к MySQL, те же функции, тот же порядок кода;
- без фреймворков (Laravel, Symfony) и Composer, если их не проходили;
- имена файлов — по смыслу задания: index.php, form.html, process.php; SQL-скрипты — отдельными файлами .sql;
- страницы и формы — по правилам дизайна; все надписи по-русски;
- сообщения пользователю короткие и без «Пожалуйста»: «Заполните все поля», «Неверный номер телефона».

## Что писать в задании
- 1–2 предложения: какой файл создан, какие данные он принимает, каким методом приходит форма и что с данными делается.
- Для БД — список: таблицы, ключевые поля, связи между таблицами.
- Разницу GET и POST показывай фактом: при GET параметры видны в адресной строке, при POST — нет.
- Значения из БД и с экрана, которых нет в запросе, не выдумывай.

## Рисунки
- окно браузера вместе с адресной строкой (localhost/…), чтобы был виден адрес: форма до отправки, результат после отправки;
- phpMyAdmin: структура таблицы, связи между таблицами, результат SQL-запроса;
- темы: «Форма обратной связи в браузере до отправки», «Результат обработки формы методом GET в адресной строке браузера», «Результат выполнения запроса с JOIN в phpMyAdmin»;
- если рисунок снимает студент, инструкция: какой адрес открыть, что ввести в форму, что нажать, что должно быть в кадре (адресная строка — обязательно).

## Листинги
- по одному файлу на листинг: «Исходный код обработчика формы process.php», «SQL-скрипт создания таблиц базы данных».
