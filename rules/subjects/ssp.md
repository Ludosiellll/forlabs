# ССП — Современные системы программирования

## Дисциплина
Архитектура и компоненты систем программирования (IDE, трансляторы, отладчики, сборка), затем практика на Java и Go.
- теоретические лабы: компоненты и классификация систем программирования, сравнение IDE (Visual Studio, Eclipse, Xcode, IntelliJ IDEA, NetBeans), рейтинги языков (TIOBE, PYPL, Stack Overflow Developer Survey, GitHub Octoverse);
- Java: установка JDK, Eclipse; примитивные и ссылочные типы, классы и иерархии классов, методы String, String.format, графика AWT/Swing (Graphics2D);
- Go: установка, VS Code; примитивные типы, массивы, срезы, функции, пакеты fmt и math/rand.

## Вариант
- Номер варианта — из запроса (из профиля). Условие обычно в приложении методички: «Согласно варианту N из приложения А необходимо …».
- Если методичка делит варианты (по журналу, по рабочему месту) и в запросе передан нужный номер, бери его. Сам вариант не выбирай.

## Что писать в задании
- вводное предложение: в какой среде и какой файл разработан, что он реализует, и двоеточие: «В среде разработки Visual Studio Code разработан файл программы task1_….go, реализующий …:»;
- список: по пункту на функцию, класс или алгоритм, с типами, диапазонами, формулами и именами;
- затем листинг (полный файл) и рисунок с результатом;
- теоретическая лаба: короткие абзацы и списки по существу; таблица — только если задание требует сравнить в таблице.

## Код
- имена файлов как в прошлых лабах: в Go task1_<суть>.go, task2_<суть>.go; в Java — класс по смыслу (StringOperations.java, Task1_MinOfThree.java);
- ввод: в Go — fmt.Scan, в Java — как в методичке; вывод — fmt.Println, fmt.Printf, System.out.println;
- проверка ввода — простым if с сообщением и return;
- надписи вывода по-русски, без рамок «=== … ===» и линий «-----»;
- в GUI-заданиях — только классы и методы из методички (Graphics2D, drawLine, fillRect, drawOval, Color и т. п.).

## Рисунки (обычно 2–5 на лабу)
- результат запуска каждой программы — по рисунку на задание: «Результат выполнения программы первого задания в консоли», «Результат заполнения двумерного массива 5 х 5 и поиска экстремальных элементов»;
- окно IDE с кодом проекта и терминалом — один на лабу: «Окно среды разработки VS Code с исходным кодом проекта», «Окно Eclipse IDE с исходным кодом проекта»;
- лаба на установку — проверка версии JDK или Go в командной строке;
- GUI-задание — окно программы с рисунком.
Если рисунок снимает студент, инструкция: какой файл запустить, какой ввод дать, что должно быть в окне.

## Листинги
- тема: «Исходный код программы <что делает>»: «Исходный код программы работы с двумерным массивом 5 х 5».

## Контрольные вопросы
- В лабах ССП обычно есть. Ответ — одно предложение по сути:
  - «Что называется функцией? С помощью какого ключевого слова определяется?» → «Именованный блок кода для многократного вызова; определяется ключевым словом func.»
  - «Допускается ли в языке Go, чтобы функция возвращала несколько значений?» → «Да, допускается.»
