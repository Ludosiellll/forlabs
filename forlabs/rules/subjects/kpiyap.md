# КПИЯП — Конструирование программ и языки программирования

## Дисциплина
Объектно-ориентированное программирование на C#: классы, наследование, объекты класса как поля другого класса (агрегация, композиция), жизненный цикл объектов и IDisposable, структуры и перечисления. Консольные приложения .NET в VS Code, сборка и запуск — dotnet build и dotnet run.

## Папки лабы
- в папке лабы — отдельная папка на каждый блок: «Пример 1», «Пример 2», …, «Индивидуальное задание»;
- в каждой — свой консольный проект с Program.cs, который собирается и запускается без ошибок;
- выполняются все разобранные в методичке примеры и индивидуальное задание.

## Примеры из методички
- Код примеров переноси из методички как есть: те же имена, вывод и комментарии. Не улучшай и не переписывай.

## Индивидуальное задание
- Вариант — из запроса (из профиля). Описание начинай с условия: «Согласно варианту N разработана программа на языке C#, реализующая …:».
- Код:
  - без комментариев вообще;
  - без декоративных разделителей в коде и выводе («-------», «=====»);
  - простой стиль, как в примерах: namespace Lab<N>, class Program, static void Main(string[] args), поля и конструктор как в методичке, метод вывода вроде Display();
  - вывод через Console.WriteLine и Console.Write с обычными русскими надписями;
  - ввод с клавиатуры с проверкой: while (!int.TryParse(Console.ReadLine(), out time)) и подсказка «Введите число: »;
  - только конструкции темы лабы и прошлых лаб; LINQ, лямбды, switch-выражения, record — только если они есть в методичке.

## Что писать в отчёте
- Пиши только по заданиям из запроса. В прошлых лабах в отчёт шло задание по варианту, а примеры оставались в папках.
- Вводное предложение с условием варианта и двоеточием, затем список: по пункту на перечисление, структуру или класс, ключевые методы и Main (что создаётся, что вводится, что считается).
- Пример пункта: «- метод GetCalories выполняет расчет пищевой ценности рецепта в килокалориях по содержанию белков, жиров и углеводов;».

## Рисунки
- окно консоли с результатом индивидуального задания: «Результат выполнения программы» или конкретнее, с предметом варианта;
- если рисунок снимает студент, инструкция: «Открой терминал в папке «Индивидуальное задание», выполни dotnet run, введи данные по подсказкам; в кадре весь вывод программы».
