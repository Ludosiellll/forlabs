# КС — Компьютерные сети

## Дисциплина
Построение и работа компьютерных сетей: стек TCP/IP, адресация, транспортный уровень (TCP, UDP), прикладные протоколы (DNS, HTTP, FTP, SMTP, POP3), анализ трафика, VLAN, NAT, маршрутизация.
ПО: Cisco Packet Tracer, Wireshark, командная строка Windows (ping, ipconfig, netstat, bat-файлы для диагностики ЛВС), RouterSim Network Visualizer.
Темы прошлых лаб: bat-файлы для диагностики ЛВС; анализ трафика DNS, HTTP, FTP; TCP и UDP с netstat; почтовые протоколы; FTP (порты 20 и 21, команды USER, PASS, RETR, ответы 331, 230, 150, 226); VLAN на основе портов (access, trunk 802.1Q, DTP, маршрутизация между VLAN через SVI и router-on-a-stick); PDU и инкапсуляция; NAT overload (PAT); базовая настройка узлов в Packet Tracer, беспроводная сеть, сохранение конфигурации в NVRAM.

## Вариант
- Адресацию, номера VLAN, имена устройств бери из варианта в запросе (из профиля). Что задано вариантом — переноси дословно.

## Команды и конфигурации
- Только реальные команды с правильным синтаксисом:
  - Cisco IOS: enable, configure terminal, hostname, interface, ip address, switchport mode access, switchport mode trunk, switchport access vlan, encapsulation dot1q, ip routing, ip nat inside, ip nat outside, show running-config, copy running-config startup-config;
  - Windows: ping, tracert, ipconfig /all, netstat -an, nslookup;
  - фильтры Wireshark: tcp, udp, http, dns, ftp, ip.addr == …, операторы &&, ||, !.
- Конфигурация устройства — отдельным листингом: «Конфигурация маршрутизатора Router0», «Команды настройки VLAN на коммутаторе Switch0».
- Адреса, маски, порты и номера VLAN одинаковы в тексте, листингах, таблицах и инструкциях.
- bat-файл — простой: @echo off, команды, echo с короткими русскими пояснениями, без рамок и эмодзи.

## Что писать в задании
- 1–2 предложения: что настроено, на каком устройстве, какими командами, чем проверено.
- Значения, которые видны только на снимке студента (номера и время пакетов, MAC-адреса, порты клиента), не выдумывай: пиши общее («в поле Destination указан адрес DNS-сервера») или бери из запроса.
- Таблица адресации — только если задание её требует.

## Рисунки — в основном вручную
Packet Tracer и Wireshark снимает студент. Для каждого рисунка — инструкция:
- Packet Tracer: рабочая область (Logical или Physical), какое устройство открыть, вкладка (CLI, Config, Desktop), какую команду выполнить, что должно быть в кадре; для проверки — режим Simulation со списком событий или Command Prompt узла с ping;
- Wireshark: на каком интерфейсе захват, что запустить для трафика, какой фильтр ввести в строку фильтра, какой пакет выделить и какие поля раскрыть;
- командная строка: какую команду выполнить и что видно в выводе.
Обычные рисунки: топология сети в рабочей области; вывод show-команды в CLI; результат ping между узлами; список пакетов с фильтром; раскрытые заголовки пакета.
Темы: «Топология сети с VLAN 10 и 20 в рабочей области Packet Tracer», «Пакеты протокола FTP с фильтром ftp в Wireshark», «Результат проверки связи командой ping между PC0 и PC2».

## Программы
- FTP-клиент — FileZilla или команда ftp в командной строке Windows: браузеры (Firefox, Chrome, Edge) FTP больше не открывают.
- В Wireshark ответы FTP-сервера (220, 331, 230, 150, 226) видны с фильтром ftp (управляющее соединение, порт 21), а сам файл — с фильтром ftp-data.
